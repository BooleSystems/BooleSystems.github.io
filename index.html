BooleOS

A bare-metal x86 hobby OS, built from scratch in C99 and NASM.

v0.20.1 · pre-1.0, active development

What it is

BooleOS is an experimental x86 (32-bit) operating system written from scratch in C99 and NASM assembly — no Linux or BSD underneath, no libc. It boots via GRUB (Multiboot2), runs kernel and user processes with real memory isolation, handles syscalls from ring 3, and has its own filesystem and driver stack.

It's developed entirely through Claude Code: every line of the implementation is AI-generated, commit by commit. The maintainer directs the project, reviews every diff, and decides what comes next, but doesn't hand-write the code. This isn't a hidden detail — it's the project's premise, and it's enforced in CONTRIBUTING.md: contributions must be AI-generated too, with a verifiable co-authorship trailer.

Still pre-1.0, still changing fast.

Status

  • ✓ Multiboot2 boot, GDT/IDT/PIC/PIT, PS/2 keyboard
  • ✓ Physical/virtual memory manager, kernel heap
  • ✓ Cooperative round-robin scheduler, preemption, fork()
  • ✓ Ring 3 usermode, syscalls via int 0x80, ELF32 loader
  • ✓ Interactive userland shell (pipes, redirects, job control)
  • ✓ ATA PIO driver, FAT16 read/write, VFS, PCI enumeration
  • ✓ Hardware abstraction layer, Safe Mode, crash handler
  • ✓ SDK for writing and running your own programs
